# 데스크이야기 (DeskIyagi)

**원격 제어와 원격 지원을 한 세션에 — 화면을 보고, 조작하고, 말하고, 파일을 보내고, 같이 그립니다. PC 와 안드로이드.**

[English](README.md) · [한국어](README_ko.md)

## 왜 데스크이야기인가

- **원격 지원에 필요한 게 창 하나에.** 화면 공유·원격 제어·음성·파일 전송·클립보드·채팅. 원격 프로그램, 전화, 메신저를 따로 켤 필요가 없습니다.
- **고치면서 말합니다.** 지연이 적은 양방향 음성 통화가 들어 있습니다.
- **말로 설명하지 말고 짚으세요.** 공유 화면 위에 화살표·상자·형광펜을 긋고, 내 마우스는 상대 화면에 코칭 포인터로 보입니다.
- **보이면 안 되는 것은 가립니다.** Privacy Blur 가 지정한 영역을 화면이 PC 를 **떠나기 전에** 모자이크합니다 — 개인정보가 아예 전송되지 않습니다.
- **휴대폰으로 도와줍니다.** 안드로이드 뷰어로 PC 화면을 보고 터치로 조작합니다.
- **사람 없는 PC 에도.** PC 를 원격 접속 대기로 두고 필요할 때 들어갑니다.
- **부드럽고 선명하게.** 하드웨어 H.265 인코딩으로 적은 대역폭에서도 화면이 깨끗합니다.

## 기능

| | |
|---|---|
| 🖥 화면 공유 | 하드웨어 인코딩 실시간 H.265 스트림 |
| ⌨️ 원격 제어 | 마우스·키보드·스크롤(한글·영문 입력) |
| 🎤 음성 통화 | 저지연 양방향 음성 |
| 📎 파일 전송 | 양방향 |
| ✏️ 드로잉 오버레이 | 화면 위 펜·형광펜·화살표·도형 |
| 🔒 Privacy Blur | 보내기 전에 지정 영역 모자이크 |
| 🔴 코칭 포인터 | 보는 쪽 마우스 위치를 상대 화면에 실시간 표시 |
| 📋 클립보드 동기화 | 양방향 텍스트 클립보드 |
| 💬 채팅 | 실시간 글자 채팅 |
| 📱 안드로이드 뷰어 | 스마트폰으로 PC 화면 보기 + 터치 조작 |
