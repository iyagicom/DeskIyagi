# DeskIyagi

**Remote desktop and remote support in one session — see the screen, take control, talk, send files and draw on it together. PC and Android.**

[English](README.md) · [한국어](README_ko.md)

## Why DeskIyagi?

- **Everything a support call needs, in one window.** Screen sharing, remote control, voice, file transfer, clipboard and chat — no juggling a remote tool, a phone call and a messenger.
- **Talk while you fix it.** Low-latency two-way voice is built in.
- **Point, don't describe.** Draw arrows, boxes and highlights on the shared screen, and your mouse shows up as a coaching pointer on the other side.
- **Hide what shouldn't be seen.** Privacy Blur masks chosen areas *before* the image leaves the PC — personal data never goes over the wire.
- **Help from your phone.** The Android viewer shows the PC screen and lets you control it by touch.
- **Reach an unattended PC.** Leave a PC waiting for remote access and connect when you need it.
- **Smooth and sharp.** Hardware H.265 encoding keeps the picture clear with little bandwidth.

## Features

| | |
|---|---|
| 🖥 Screen sharing | Real-time H.265 stream with hardware encoding |
| ⌨️ Remote control | Mouse, keyboard and scroll (Korean and English input) |
| 🎤 Voice call | Two-way, low-latency voice |
| 📎 File transfer | Both directions |
| ✏️ Drawing overlay | Pen, highlighter, arrows and shapes on the screen |
| 🔒 Privacy Blur | Mask areas before they are sent |
| 🔴 Coaching pointer | The viewer's mouse shown live on the host |
| 📋 Clipboard sync | Two-way text clipboard |
| 💬 Chat | Real-time text chat |
| 📱 Android viewer | View and control the PC by touch |
